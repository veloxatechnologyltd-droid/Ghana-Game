# Character animations

Motion-captured walk, run, idle and talk clips for the Rocketbox adults, from the [Microsoft Rocketbox animation library](https://github.com/microsoft/Microsoft-Rocketbox/tree/master/Assets/Animations) under the accompanying [MIT license](LICENSE.md). They use the same `Bip01` skeleton as the avatars, so no retargeting is needed.

| Key | Source clip |
|---|---|
| `walkM` / `walkF` | `all_animations_max_motextr_xy/m_walk_neutral`, `f_walk_neutral` |
| `runM` / `runF` | `all_animations_max_motextr_xy/m_run_neutral`, `f_run_neutral` |
| `idleM` / `idleF` | `all_animations_max_motextr_static/m_idle_breathe_01`, `f_idle_breathe_01` |
| `talkM` / `talkF` | `all_animations_max_motextr_static/m_gestic_talk_neutral_01`, `f_gestic_talk_neutral_01` (a seamless 6–7.5 s loop cut from the take) |

`rocketbox-anims.json` is generated by `convert.mjs` from the source `.max.fbx` files. It keeps only the body bones' rotations and the root bob, removes forward travel so walk and run play in place, records each cycle's `stride` (cm) so playback can follow ground speed, and stores `off` (run phase that matches the walk's footfall). To regenerate, download the eight source files into a folder and run:

```bash
node assets/characters/animations/convert.mjs <folder> assets/characters/animations/rocketbox-anims.json
```
