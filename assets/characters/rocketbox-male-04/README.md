# Detailed male character

Source: [Microsoft Rocketbox Male Adult 04](https://github.com/microsoft/Microsoft-Rocketbox/tree/master/Assets/Avatars/Adults/Male_Adult_04). Original FBX and textures are under the accompanying [MIT license](LICENSE.md).

The `m006_*.webp` files are resized and compressed from the source TGA textures for local browser loading. The model is used for Kwesi and selected nearby adult men. Its clothing and appearance are those of the source asset, not a bespoke Ghanaian character design.
