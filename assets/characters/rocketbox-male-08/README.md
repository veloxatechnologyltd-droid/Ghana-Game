# Detailed male character

Source: [Microsoft Rocketbox Male Adult 08](https://github.com/microsoft/Microsoft-Rocketbox/tree/master/Assets/Avatars/Adults/Male_Adult_08). Original FBX and textures are under the accompanying [MIT license](LICENSE.md).

The `m014_*.webp` files are resized and compressed from the source TGA textures for local browser loading. This model provides a second adult man's look alongside Male Adult 04. Its clothing and appearance are those of the source asset, not a bespoke Ghanaian character design.
