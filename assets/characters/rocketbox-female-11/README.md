# Detailed pedestrian asset

Source: [Microsoft Rocketbox Female Adult 11](https://github.com/microsoft/Microsoft-Rocketbox/tree/master/Assets/Avatars/Adults/Female_Adult_11). The original FBX and texture files are distributed under the accompanying [MIT license](LICENSE.md).

`Female_Adult_11.fbx` is the original rigged model. The seven `f011_*.webp` files were resized from the source's 2048 px TGA textures to 1024 px and encoded as WebP for browser delivery. The game maps the FBX texture references to these local WebP files. Walking movement is generated in `three-scene.js` from the source skeleton; no separate animation file is included.

This is one detailed-character pilot. The source outfit is a contemporary brown dress and does not yet represent a Ghana-specific clothing design.
