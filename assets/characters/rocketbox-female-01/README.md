# Detailed female character

Source: [Microsoft Rocketbox Female Adult 01](https://github.com/microsoft/Microsoft-Rocketbox/tree/master/Assets/Avatars/Adults/Female_Adult_01). Original FBX and textures are under the accompanying [MIT license](LICENSE.md).

The `f001_*.webp` files are resized and compressed from the source TGA textures for local browser loading. This model provides a second adult woman's look alongside Female Adult 11. Its clothing and appearance are those of the source asset, not a bespoke Ghanaian character design.
